# Persona Walkthrough Specialist

_Generated by `scripts/build_skill_graph.py` from the registry and cards. Edit the source, not this note._

Persona walkthrough specialist is a 3RDWRONG design QA specialist for ux-audit, activated when the approved scope specifically requires ux audit expertise.

- **Role:** specialist
- **Job:** [[design--ux-audit|ux audit]] (design-qa)
- **Department:** [[skill-graph/Design|Design]]
- **Card:** `toolkit/cards/design/design-qa/agency--design-persona-walkthrough.md`
- **Invoke:** Agent tool: design-persona-walkthrough

## What it does

- Build a fully specified persona from search context, fears, trust triggers, decision style and goal.
- Walk the supplied page fold by fold with separate raw persona monologue and analyst assessment.
- Apply LIFT, Cialdini and Fogg lenses; check the five-second test and CTA reachability.
- Prioritise recommendations by effort and impact, noting trade-offs between personas.

## When to use

- When the approved scope specifically requires ux audit expertise. In practice: during experience design or validation, against the named user task and flow.

## When not to use

- Do not use it to certify accessibility or production readiness; use `skill:accessibility` for design-level access risks and `skill:reviewing-interface-quality` for rendered interface quality.

## How to run it

1. Confirm the exact surface, task, scope and evidence before judging.
2. Apply only the source tool’s relevant method and record concrete observations.
3. Prioritise findings by user consequence and pair each with a usable next action.
4. State evidence gaps and route any specialist checks to the relevant owner.

Separate Documented, Interpretation, Hypothesis and Unknown where evidence claims are made; mark untested checks explicitly. ```
