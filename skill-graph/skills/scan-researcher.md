## What it does

- Restricted read-only vulnerability researcher dispatched by the Claude Security scan workflow; not for direct invocation or general exploration.
- CRITICAL — severe impact and nothing in the way: over the network, simple, no precondition, no privileges, no victim. Unauthenticated remote code execution, full authentication bypass, wholesale data exposure.
- HIGH — severe impact on at least one property with a realistic path, but one real hurdle: privileges, victim interaction, a deployment precondition, or a defense to defeat.
- MEDIUM — a real vulnerability with bounded impact, or serious impact behind several restrictive conditions. Information disclosure and user enumeration are findings; they belong here.

## When to use

- only when the Claude Security scan workflow dispatches a read-only vulnerability researcher.

## When not to use

- Do not use it outside the stated scope or without authorisation for active testing.
- Do not treat a scan as proof that no vulnerabilities exist.

## How to run it

1. Start the Claude Security workflow; this agent is dispatched only for its assigned workflow stage.
2. Provide the scope, evidence and decision requested; keep client material in an approved private workspace.
3. Review the result against the checks below; a human retains release and approval decisions.

```text
Within the Claude Security workflow, dispatch Agent tool: scan-researcher. Task: {describe the scoped security analysis need}. Context: {repository or artefact and constraints}. Evidence: {files, links and runtime evidence}. Return findings with evidence, scope, unknowns and practical next steps; do not claim checks you did not perform.
```
