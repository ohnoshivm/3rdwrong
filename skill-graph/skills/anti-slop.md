# Anti Slop

_Generated by `scripts/build_skill_graph.py` from the registry and cards. Edit the source, not this note._

Anti Slop is a 3RDWRONG design QA specialist for visual-qa-browser, activated when a supplied generated interface exhibits a specific decorative cliche that needs removal.

- **Role:** specialist
- **Job:** [[design--visual-qa-browser|visual qa browser]] (design-qa)
- **Department:** [[skill-graph/Design|Design]]
- **Card:** `toolkit/cards/design/design-qa/vectorlab-ux-skills--anti-slop.md`
- **Invoke:** /anti-slop

## What it does

- Removes a specific decorative cliché from a supplied generated interface.
- Keeps the remaining interface coherent with the provided design direction.
- Limits the review to the identified cliché and its visible consequences.

## When to use

- A supplied generated interface exhibits a specific decorative cliche that needs removal. In practice: after a meaningful interface change, when rendered browser evidence is available.

## When not to use

- Do not use it for unrendered concept critique or to make fixes unless its source explicitly allows edits; use `skill:3w-identity-system-critic` for identity concepts.

## How to run it

1. Confirm the page loads and capture the stated widths/states before reporting.
2. Exercise the named flow; inspect screenshots and measurements that support each finding.
3. Report location, observed/expected behaviour, impact, evidence and fix owner.
4. Mark inaccessible or untested widths and behaviours unverified, then re-check fixes against the same evidence.
