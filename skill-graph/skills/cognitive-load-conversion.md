# Cognitive Load Conversion

Cognitive-load-conversion is a 3RDWRONG design QA specialist for ux-audit, activated when the approved scope specifically requires evaluating cognitive load or persuasion in a conversion flow.

- **Role:** specialist
- **Job:** [[design--ux-audit|ux audit]] (design-qa)

- **Card:** `toolkit/cards/design/design-qa/skill--cognitive-load-conversion.md`
- **Invoke:** /cognitive-load-conversion

## What it does

- Separates intrinsic task effort from removable extraneous load.
- Audits visual clutter, mental-model mismatches and tasks that can be offloaded.
- Returns three to five prioritised changes tied to specific UI elements and likely impact.
- Uses the squint and first-time tests to locate friction.

## When to use

- When the approved scope specifically requires evaluating cognitive load or persuasion in a conversion flow. In practice: during experience design or validation, against the named user task and flow.

## When not to use

- Do not use it to certify accessibility or production readiness; use `skill:accessibility` for design-level access risks and `skill:reviewing-interface-quality` for rendered interface quality.

## How to run it

1. Confirm the exact surface, task, scope and evidence before judging.
2. Apply only the source tool’s relevant method and record concrete observations.
3. Prioritise findings by user consequence and pair each with a usable next action.
4. State evidence gaps and route any specialist checks to the relevant owner.
