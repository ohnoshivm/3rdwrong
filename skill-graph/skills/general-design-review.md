# General Design Review

_Generated by `scripts/build_skill_graph.py` from the registry and cards. Edit the source, not this note._

General-design-review is a 3RDWRONG design QA specialist for ux-audit, activated when the approved scope specifically requires reviewing an existing interface or user flow for usability and quality.

- **Role:** specialist
- **Job:** [[design--ux-audit|ux audit]] (design-qa)
- **Department:** [[skill-graph/Design|Design]]
- **Card:** `toolkit/cards/design/design-qa/skill--general-design-review.md`
- **Invoke:** /general-design-review

## What it does

- Combines UX, product and AI design lenses into a compact review.
- Selects the closest lens for the issue and skips irrelevant frameworks.
- Returns a verdict, three to five top issues, consequences, changes, open questions and next step.
- Includes focused WCAG and visual-craft passes when relevant.

## When to use

- When the approved scope specifically requires reviewing an existing interface or user flow for usability and quality. In practice: during experience design or validation, against the named user task and flow.

## When not to use

- Do not use it to certify accessibility or production readiness; use `skill:accessibility` for design-level access risks and `skill:reviewing-interface-quality` for rendered interface quality.

## How to run it

1. Confirm the exact surface, task, scope and evidence before judging.
2. Apply only the source tool’s relevant method and record concrete observations.
3. Prioritise findings by user consequence and pair each with a usable next action.
4. State evidence gaps and route any specialist checks to the relevant owner.
