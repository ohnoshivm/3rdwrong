## What it does

- Retrieves project screens and assets from Stitch for analysis.
- Creates or updates a Stitch design system from a DESIGN.md.
- Applies the design system to selected screens.- **Option B (Direct MCP Tool)**: If the `DESIGN.md` is small (under ~5KB), you can call the `upload_design_md` MCP tool directly, passing the base64-encoded design markdown content as `designMdBase64`.

## When to use

- An existing Stitch project needs design-system assets or token changes applied through Stitch MCP.
- In practice: use it at Phase 03 Design System when that specific operation is in the approved scope.

## When not to use

- When the approved direction, source artefact or required inputs are missing; ask for them before proceeding.
- For a request outside this scope, start with the job lead `design-skills:design-systems` and use another specialist only when its trigger applies.

2. Run the scoped system operation in the existing design authority and preserve declared exceptions.
