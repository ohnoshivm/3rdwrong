## What it does

- Reviews a diff or commit with security risk as the organising principle.
- Checks changed files, removed security logic and blast radius for high risk.
- Produces concrete attack scenarios and a report.

## When to use

- Use for engineering/engineering-qa-security/security-analysis when the brief specifically requires: Performs security-focused differential review of code changes .

## When not to use

- Do not use for a full security scan of an unchanged repository.
- Do not skip checks because a change appears small.
