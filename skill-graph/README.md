## How to read this

- Open a department, then a job. Read the job’s lead first; specialists load only when their trigger applies.
- Bench tools are fallbacks. They are listed in each job note and have no notes of their own.
- Each skill note carries its card’s guidance and the skills it pairs with.
- Workflow shows the order a project uses the skills in.
