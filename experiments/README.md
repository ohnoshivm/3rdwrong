# Creative technology experiments

Use this area for bounded creative-technology, typography, motion, generative,
interaction or production experiments that answer a real design question.

Each experiment lives in a named folder only when it exists. Include a concise
README that states the question and status, the result, the evidence and what
it changes. Store code and captures with clear provenance; avoid client files
and unlicensed assets.

The proposed [Creative Technology starter repertoire](creative-technology-repertoire.md)
sets the five initial non-client studies; no study is claimed complete.

Start from [the experiment template](../templates/learning/experiment.md).
Record the hypothesis, setup, tool and version, what was tried, observed
result, evidence and decision: adopt, iterate or drop. Experiments are not
proof of audience response unless an appropriate study supports that claim.

Link a useful outcome back to the relevant principle, method or skill. Do not
turn every observation into a rule; preserve context and uncertainty in the
[learning loop](../methods/learning-loop.md).

**Proposed publication model:** experimental code is intended to use MIT; the
licensing proposal remains pending founder confirmation at publication. See
[decision D-0009](../studio/decisions/0009-licensing-model.md).
