# Fictional examples

**Fictional example for testing methods and skills. Not a client.**

Files here are synthetic inputs and outputs for checking whether studio
methods and Agent Skills produce useful work. They contain no client results,
real interviews or market findings. Evidence marked **Documented** refers only
to facts stated inside the fictional brief or fictional research notes.

The sample brand is **Stillsoil Atelier**, a fictional founder-led Indian
premium personal-care business. Exact-phrase web searches for `"Stillsoil
Atelier" brand` and `"Stillsoil" personal care brand India` on 2026-10-22
surfaced unrelated soil and forum references, not an obvious existing consumer
brand. This is a basic discoverability check only, not a claim about trademark
clearance or proof that the name is available.

See the sample project's [fictional brief](stillsoil-atelier/brief.md),
[discovery synthesis](stillsoil-atelier/discovery-synthesis.md),
[concept route A](stillsoil-atelier/concept-route-a.md) and
[identity-system critique](stillsoil-atelier/identity-system-critique.md). The
two runs have [discovery skill evaluation](stillsoil-atelier/brand-discovery-evaluation.md)
and [3w-identity-system-critic skill evaluation](stillsoil-atelier/identity-system-critic-evaluation.md).
Each project file repeats the required fiction banner.
