# Typography system skill evaluation — Stillsoil Atelier

**Fictional example for testing methods and skills. Not a client.**

## Skill and version

`3w-typography-system` 0.1.0 was run; findings below produced version 0.1.1 of [the skill](../../../skills/3w-typography-system/SKILL.md). The run was not repeated on 0.1.1.

## Test request and inputs

**Request:** "Use 3w-typography-system on route A for Stillsoil Atelier as a formative run. Shortlist by role, set hierarchy and fallbacks, and record licence and script checks; do not name or assess real fonts, and do not approve anything."

Inputs: [fictional brief](brief.md), [discovery synthesis](discovery-synthesis.md), [concept route A](concept-route-a.md) and the [formative critique](identity-system-critique.md), plus the [mark test run](mark-exploration-test-run.md). Route A is not chosen and strategy is not signed, so the run was accepted as formative. No category audit, artwork, dimensions, printer or licences exist in the fiction.

Output: [typography system test run](typography-system-test-run.md).

## Procedure followed

Steps 1–3, 6, 7, 9 and 11 were followed in text with fictional candidates T1–T3. Steps 4, 5, 8 and 10 (licences, shaping, optical sizes, file sizes) could not run on fictional fonts and are recorded as Unknown or Not measured; step 12 application tests were rules only.

## Output review

- The type's job came from the brief's problems (three unrelated typefaces, mobile crop, shelf-card scanning), not from a mood.
- The run chose one family as the starting decision and recorded why a second would be added.
- Licence and script support stayed Unknown instead of being assumed.
- The wordmark was kept as drawn artwork, consistent with the mark run.

## What worked

- The constraint table surfaced two blocking unknowns early: required scripts and mandatory label text.
- The budget line tied the shortlist to web standards and D-0023 before any font was chosen.
- The "never truncate, wrap first" rule addressed the fictional founder's crop defect and was shared with the composition run.

## Gaps and observed failure

- **Mandatory text missing as an input.** Labels carry ingredients and regulatory lines that set the smallest type size; the skill did not ask for them, and it must not decide them itself.
- **No specimen string set.** "Real text" was required but not defined, so the run had to invent the list.
- **Stop condition too strict.** With scripts unconfirmed, the skill said stop; the useful behaviour is to continue for confirmed scripts and deliver the rest as unverified.
- **Formative use blocked** as in the other craft skills.

## Skill changes made

- Inputs: mandatory text with minimum sizes, confirmed by the client from the applicable rules.
- Step 5: build the specimen string set first; non-Latin strings supplied or checked by a fluent reader.
- Failure conditions: continue for confirmed scripts; unconfirmed scripts delivered as unverified; formative runs allowed when accepted.

## Remaining limits and next evaluation

- With fictional fonts, licensing, shaping, optical sizes and web-font weight were not exercised — the most important parts of the method. The next evaluation must use real candidate fonts, read their licences and shape a Devanagari or Kannada specimen with a fluent reviewer.
- The judgement to author this skill rather than rely on `agent:visual-designer` rests on that agent's file, which covers digital tokens and ramps but not licensing, scripts or selection against the idea.
