# Mark exploration skill evaluation — Stillsoil Atelier

**Fictional example for testing methods and skills. Not a client.**

## Skill and version

`3w-mark-exploration` 0.1.0 was run; findings below produced version 0.1.1 of [the skill](../../../skills/3w-mark-exploration/SKILL.md). The run was not repeated on 0.1.1.

## Test request and inputs

**Request:** "Use 3w-mark-exploration on route A for Stillsoil Atelier. This is a formative run: produce routes, the construction checklist and the test matrix as text; do not approve anything or claim registrability."

Inputs: [fictional brief](brief.md), [discovery synthesis](discovery-synthesis.md), [concept route A](concept-route-a.md) and the [formative critique](identity-system-critique.md). Route A is not chosen and strategy is not signed, so the run was accepted as formative. No category audit, artwork, dimensions, printer or licences exist in the fiction.

Output: [mark exploration test run](mark-exploration-test-run.md).

## Procedure followed

Steps 1–4 and 9–13 were followed in text. Steps 5–8 (vector work, optical corrections, size and medium renders) were converted into planned checks because no artwork exists; each is marked Unknown or Not run rather than passed.

## Output review

- The idea was stated without visual adjectives before any form, and it tied the mark to the route's "pause" rather than to a style.
- Three routes differ in organising idea (an interval in the name, a press mark, a bracket device); a style-only monogram was rejected with a reason.
- Distinctiveness stayed Unknown without an audit; registrability stayed a caution list plus a legal step.
- No unsupported claim of memorability or recognition was made; R3's recall note was used as Interpretation only.

## What worked

- The adjective-free idea test forced a mark idea that also serves the system (the interval became a spacing unit used by the composition run).
- The test matrix made clear which tests are impossible without artwork, so nothing was reported as passed.
- The registrability wording held: generic devices were flagged, no verdict given.

## Gaps and observed failure

- **Formative use blocked.** Failure conditions said to stop without a chosen route; the studio needs formative runs during concept, as the critic skill allows.
- **Mark type chosen by habit risk.** The procedure did not ask whether the name or a symbol must carry recognition; R3's recall note made this the central decision.
- **16 px with a long wordmark.** A nine-letter wordmark cannot hold at 16 px; the skill said "simplified variant if needed" instead of requiring a decision on what represents the brand below the minimum.
- **Print minimums.** Sizes were listed only in pixels; labels need a physical minimum in millimetres.
- **Brand architecture.** No input asked whether the mark signs a product line, which matters for four products.

## Skill changes made

- Failure conditions: formative runs allowed when accepted, labelled throughout, with no final minimum sizes (addresses formative blocking).
- Inputs: brand architecture and recall evidence added.
- Step 2: constraints include print sizes in mm and a labelled decision on whether the name or a symbol carries recognition.
- Step 7: an explicit decision on what represents the brand below the master's minimum size.
- Step 8: physical minimum in millimetres for the smallest print application.

## Remaining limits and next evaluation

- No vector, render or emboss proof exists, so the construction and optical-correction checklist was not exercised; the next evaluation needs drawn artwork and real renders at 16–48 px.
- One fictional run is not evidence of reliability; test a symbol-led brief and a Devanagari wordmark next.
- A human designer must review the routes; the maker of this run was not independent.
