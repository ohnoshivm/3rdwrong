# Image-generation prompts for Oryzo Red

The image agent (GPT-6 Luna, medium effort, brief [08](08-oryzo-red-img-gpt-image-generation.md)) wrote these prompts from the director's art direction and sent each one to the built-in GPT image-generation tool on 30 October 2026, between 23:41 and 23:53 IST. It produced 12 images; a deterministic script then derived the alpha and height maps for the seven props and a height map for the cork, for 27 files in all. None was regenerated.

The prompts are verbatim (American spellings such as "centered" and "color" are the agent's). The only change from the working file is this introduction. The images themselves are in the private study build; a contact sheet is in [`media/f11-generated-assets.jpg`](../../../media/f11-generated-assets.jpg).
