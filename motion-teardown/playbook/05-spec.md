# Stage 5: Spec

**Purpose.** Turn the reconciled report into a build specification that several agents can follow without talking to each other: decisions made, a shared contract, file ownership, assets named, acceptance written as checks. Everything an agent would otherwise have to guess goes into this file.

**Case.** The founder asked for an exact rebuild of the oryzo.ai (by [Lusion](https://oryzo.ai)) hero and first section in red and white, with images generated by GPT. At 23:06 the founder asked for it. Four decisions followed in a single multiple-choice prompt (23:36 in the session record), `BUILD-SPEC.md` was written by about 23:40 and three build agents launched.

## Inputs → outputs

| In | Out |
| --- | --- |
| `RE-REPORT.md` and its rebuild checklist | `BUILD-SPEC.md`, built from [build-spec-template.md](../agent-system/templates/build-spec-template.md) |
| The human's answers to the real decisions | `src/contract.ts`, from [contract-template.ts](../agent-system/templates/contract-template.ts) (the exact text, to be copied byte for byte) |
| | An **ownership table**: path pattern → agent |
| | An **acceptance list** of scripted checks |

## Steps

1. **Collect the real decisions and ask them once.** What is genuinely the human's to choose? In our case four things (colours, how to make the prop images, which font, what copy), asked in a single multiple-choice prompt with a recommended option each. See [asking the human](../tracks/ai-builder/asking-the-human.md).
2. **Decide the stack from the evidence.** The original uses three.js and one GSAP plugin, no ScrollTrigger, no Lenis. Our spec: Vite, TypeScript, vanilla three.js and SplitText only. "No React, no Lenis, no ScrollTrigger: the original's own scroll model is ported." One scroll engine, never two.
3. **Write the decisions table** and the **palette table** (original → ours), with hex values, so that no agent invents colours. Ours: crimson `#e3141b`, cream `#fff6f4`, ink `#140304`, and a `#ai` background `#5a0c12`.
4. **Split the work along file lines.** Our three build agents were DOM (scaffold, scroll engine, text, layout), GL (renderer, scene, hand, post chain) and IMG (generated images). Each owns a set of paths and may not touch another's.
5. **Write the contract file first.** A typed interface carrying the per-frame state from DOM to GL: time, `dt`, scroll position, the section scalars, mouse, the text rect for the blur, a mobile flag, a reduced-motion flag, plus a `Stage` with `ready`, `update` and `resize`. Every agent codes against it, and nobody edits it. The text is in the spec so any agent can create it if it is missing, with exactly that content.
6. **Define failure behaviour.** `stage.ready` must settle within 10 seconds ("no silent hangs"); GL runs on flat placeholders until generated images exist; DOM must run alone if GL fails to load. These three lines remove most coordination.
7. **Name every asset** with its size and aspect, and say which come from the study mirror (and are never committed) and which are new.
8. **Write acceptance as commands.** Build passes; a script scrolls to these twelve positions (0, 270, 900, 1530, 2250, 3060, 3600, 4320, 5130, 6000, 7200, 8100 px at 1440×900) and saves screenshots to compare with the originals; the same at 390×844; 60 fps; CLS 0; clean console; reduced motion works.
9. **Run a spec dry-read.** Re-read it as the least-informed agent that will receive it. Anything that needs a question is a gap.

## Evidence to collect

- The human's answers, verbatim, with date and time.
- Each decision's rationale in one line.
- The contract text, the ownership table, the palette, the asset list and the acceptance checks in one file.
- A list of what is explicitly out of scope.

## Common traps

- **A decision the original made for you.** *Ours: the font.* The original's Halyard Display is licensed through Adobe Fonts, and our measurements flagged it. We asked rather than assumed, and chose a free substitute (Albert Sans, under the SIL Open Font Licence). If a licence is involved, it is a decision.
- **Ambiguity in ownership.** If two agents could plausibly write one file, one of them will. Resolve it in the table.
- **A contract that grows.** Every field added after agents start forces rework. Settle the fields when you write the spec, then freeze them.
- **Specs that describe, not decide.** "Use the original's formulas" is not a decision. Cite the report section and the exact formula, or paste the table.
- **Hex values left to taste.** Put every colour in a table.
- **A hang disguised as a dependency.** If GL waits for IMG, GL stalls. Placeholders break the dependency.

## Done when

- [ ] All real decisions are answered and written down.
- [ ] The contract text is in the spec, exact, and says "never change".
- [ ] Every path in the project has an owner; no path has two.
- [ ] Failure behaviour (ready timeout, placeholders, DOM-only fallback) is stated.
- [ ] Palette and assets are tables, not prose.
- [ ] Acceptance is a list of commands and positions, not adjectives.
- [ ] Someone who has not seen the report could build from the spec alone.
