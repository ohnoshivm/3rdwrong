# Inbox

Use this folder for rough, public-safe notes, links, and observations that are not ready for a permanent home. Capture only material suitable for this public repository. Personal, client, confidential, or commercial information belongs in the private system; see the [public-private boundary](../docs/public-private-boundary.md).

Each note needs only this frontmatter:

```yaml
---
title: Short note title
captured: 2026-10-22
type: inbox
status: proposed
---
```

Review the inbox weekly. Turn useful notes into a research study, principle, experiment, decision, or method change, then remove the captured note; delete anything that is not useful. The validator warns when a note is more than 30 days old. See the [capture and triage workflow](../docs/workflows.md#11-capture-a-quick-note-and-weekly-triage).
