# Pilot delivery run log

Copy this proposed template to a new pilot record. Keep the synthetic boundary
visible. Empty fields are Unknown, not passes. Do not invent elapsed time,
participant data, approval, consent or production evidence.

## Run and scope

- Run ID / date / status: not started.
- Fictional brief version/hash and source boundary: Unknown.
- Fictional Identity + Digital scope extension / accepted by / date: pending.
- Integrated playbook paths, versions and reconciliation notes: pending.
- Private/sandbox artefact location and publication permission: pending.
- Reference-pack ID, principles and no-copy list: pending.
- Tool revisions, model IDs/settings, prompts and same-brief/time constraints:
  pending; keep these hidden from the judge until score freeze.
- Human craft owner / makers / independent checker / Production logger /
  actual human gate decision-maker: unassigned roles.
- Target browser/device/network/viewport profiles and D-0023 budgets: pending.
- Scorecard version and proposed weights frozen before execution: pending.

## Stage record — copy for all 19 stages

Stage ID / method / applicable playbook stage: Unknown.
Decision requested / entry gate evidence / phase version: Unknown.
Inputs / SHA-256 / output format / acceptance conditions: Unknown.
Tool/model and revision / settings / maker: Unknown (operator-only until reveal).
Output version / sanitised slot artefact bundle / evidence references: Unknown.

| Activity | Owner role | UTC start | UTC end | Active minutes | Wait minutes | Rework minutes | Evidence label / source |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Make / judge / revise / gate | Unassigned | Not started | Not ended | Unknown | Unknown | Unknown | Unknown |

Record active work separately from waiting; rework is a subset of active time,
not added twice. Log per role so parallel work does not imply elapsed wall
clock time. State how totals were computed.

Consolidated feedback round 1 / round 2 / extra-round change decision: not run.
Strategy sign-off, route selection, visual sign-off, launch and receipt are
separate entries. A model verdict or a score is not a human decision.
