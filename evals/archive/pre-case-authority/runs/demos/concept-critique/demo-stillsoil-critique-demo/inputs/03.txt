# Stillsoil Atelier concept route A

**Fictional example for testing methods and skills. Not a client.**

> This route is invented for a skills test. It is not commissioned work or a
> recommendation for any real brand.

## Formative strategic frame

For this test only, use the fictional brief's stated direction: feel “considered,
not clinical”; make product and variant easy to identify; remain coherent on an
agreed label, line sheet and online shop. This is an **Interpretation** of the
fictional brief, not a signed strategy or approved positioning.

## Idea

**Pause with purpose:** give the cleansing step a visible pause so the routine
feels considered.

## Short route description

The label places the product name in a quiet, centred field, with the variant
set below it. A generous open area frames the name. A tall serif wordmark and
warm uncoated stock suggest a slower pace. On the online shop, the name appears
first and a restrained fade reveals the variant after it.

The route is described only as text; no finished logo, layout file, contrast
pair, font licence, script specimen, line sheet, mobile screenshot or print
proof is supplied. No category sample is supplied. The route has not been
approved.
