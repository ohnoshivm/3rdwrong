# 1. Watch: describe what is visible

Read the installed watch skill, including its setup, privacy and engine rules.
Use its configured engine. A cloud failure is a recorded failure; follow its
explicit switch policy before extracting locally. Do not silently upload private
recordings or install speech models. For a silent motion study, frames suffice.

Record source identity, duration, viewport if known, extraction settings and
actual frame timestamps. View every selected frame required by the watch
workflow. Transcripts do not establish visual facts. Keep raw media private.
Write `MOTION-PLAN.md` with `templates/motion-plan-template.md`.

List visible states, direction changes, UI behaviour and likely effect IDs.
Label mechanisms as hypotheses. A scroll reversal in the recording is not a
new forward section. Do not infer time-based animation from the video clock.

Exit: frame index, provisional effect list, unknowns and source provenance.
Keep the A/B/C lanes running while this map becomes more precise.
