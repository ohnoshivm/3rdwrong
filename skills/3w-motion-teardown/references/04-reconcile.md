# 4. Reconcile: test the causal claim

Use `reconcile-checklist.md` and `re-report-template.md`. Review every effect,
not just the most convincing screenshot. Implementation evidence order is
code > measured > video. Confirm the code belongs to the executed path and the
measured asset belongs to the scoped scene. Preserve unresolved contradictions.

For each dispute write: earlier hypothesis; source IDs; units and viewport;
competing explanation; discriminating probe; result; confidence; open limit.
For scrubbed/triggered classification compare both scroll directions at the
same y and fixed elapsed time. Stationary scroll plus pointer and time controls
separate hover response from a glow that happens to appear underneath a cursor.

Oryzo corrections to learn from: the hero desk was a layered photo and props;
later-section splats were irrelevant. The hand pose was scroll-scrubbed; dark,
32×20 grayscale frame matching falsely suggested a timer. Edge glow was gated
by scroll; only fingers responded to pointer bands. The recording reversed.

Treat frame-match and similarity scores as candidate finders. Inspect native
resolution anchors and property curves. Store `inferred` with its confirmation
probe. Export schema-valid effects and map in your own words, never source code.
Exit: a bounded report that names residual unknowns and updates earlier claims.
