# Taste practice

**Status: proposed.** This is a flexible practice menu. Adapt it to current
project needs and record evidence of change. The activity choices are proposed from *Founding
Blueprint v1.0, 22 October 2026 (private archive)*. The practice loop is distinct from the
[knowledge loop](learning-loop.md): one improves a craft decision; the other
turns a lesson into reusable studio knowledge.

## Practice menu

Use this as a flexible weekly menu; choose activities according to the current
learning question.

| Activity | Useful evidence to keep |
| --- | --- |
| Analyse two references from different fields | One principle per reference, source and context; one original application that does not reproduce the reference. |
| Typography and composition studies | Before-and-after crops, script and size tested, hierarchy rationale, and the defect corrected. |
| Concept challenge | A one-sentence idea without style adjectives, rough sketches, alternative territories and the choice criteria. |
| Critique and revision | Written critique, severity, next action, changed artefact and unresolved question. |
| Creative coding or motion | Brief, interaction or communication need, prototype version, fallback and evidence that motion adds value. |

Choose activities that address a real learning question. Completing every row
each week is not a requirement. Don't confuse collecting references with
practice or polished output with improvement.

Use [studio website taste references](../taste/studio-websites.md) as one source for reference analyses;
these calibrate taste without changing policy or the client offer.

## Practice loop

1. **Observe** a designed artefact or behaviour in its original context.
2. **Explain** the decision or effect in plain language, separating evidence
   from interpretation.
3. **Reconstruct principles** that could transfer without copying its form.
4. **Apply** one principle in an original project or bounded exercise.
5. **Critique** the result against its intention and actual constraints.
6. **Revise** and compare the result with the earlier version.

## Connection to the knowledge loop

The practice loop generates an artefact and a situated learning observation.
The knowledge loop then asks whether that lesson belongs in a principle,
research insight, method, template, automated check, skill or documented
exception. Preserve the original context and uncertainty. Not every useful
observation should become a rule.

## Review

Review the practice record periodically for repeated strengths, repeated
defects and missing evidence. Ask a suitably experienced practitioner for
critique where independent judgement is needed. Update the practice plan only
when the learning question changes; do not turn a streak or activity count
into proof of competence.
