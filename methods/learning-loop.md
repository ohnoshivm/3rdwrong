# Learning loop

Use a deliberate loop to turn observations into better work without making a
single project carry more certainty than it earned.

1. **Discover:** capture a specific observation close to its source.
2. **Analyse:** ask what it changes, what else may explain it and which context
   limits its use.
3. **Extract principles:** state a candidate principle only when it can guide
   more than one decision; keep a one-off lesson local.
4. **Apply:** try the candidate in a new context or project where appropriate.
5. **Critique:** compare the result with the original evidence and note
   counterexamples.
6. **Revise:** narrow, change or drop the candidate when it does not hold.
7. **Document:** record the source, context, uncertainty, status, owner and
   next review point.
8. **Reuse:** point methods, templates, checks or skills to the learning when
   it will change a future decision.

## Where lessons land

| Learning type | Destination |
| --- | --- |
| Stable, transferable design guidance with supporting evidence | Proposed principle |
| Source-backed fact or study finding | Research insight with source and access date |
| Improved way to perform a recurring phase | Method |
| Better prompt or decision record | Template |
| Deterministic check that can prevent repeated defects | Automated check |
| Repeatable agent workflow with observable output | Skill |
| Useful exception that should remain contextual | Documented exception |

Do not turn every observation into a rule. Preserve context, sample limits,
conflicting evidence and uncertainty. One successful application does not prove
universal effectiveness. Proposed changes to an approved decision require
human review and a new decision record; never silently promote a lesson.

## Review cadence

Review learning at project close and when a repeated issue is observed. Revisit
candidate principles and skills during the next maintenance review, using new
examples and counterexamples. Retire or supersede material that no longer
helps, and retain the reason for the change. A cadence is a reminder to review,
not a claim that evidence will arrive on schedule.
