# Methods index

Methods are proposed operating guidance. They do not create client approvals or
prove outcomes. The identity engagement runs through
[Discovery → Diagnosis → Strategy → Concept → Identity → System → Validation → Delivery → Learning](identity-engagement/README.md).

- [Delivery playbooks](playbooks/README.md) say who runs each lifecycle stage,
  identity phase and Digital Experience stage, with which tools, checked by
  whom; [handoffs](handoffs/README.md) define what passes between departments.
- [Living identities](living-identities.md) sets a decision test for motion,
  generative, adaptive and interactive extensions.
- [Perception-to-identity map](perception-to-identity-map.md) links the
  commercial problem to audience understanding, creative expression and
  validation; it is a proposed framework, not an academic model.
- [Creative guardrails](creative-guardrails.md) turn research, tool and craft
  choices into practical boundaries.
- [Taste practice](taste-practice.md) gives the flexible craft loop and its
  connection to the knowledge loop.
- [Learning loop](learning-loop.md) routes observations into reusable knowledge
  while preserving context and uncertainty.
- [Critique protocol](quality/critique-protocol.md) defines evidence and
  severity for reviews.
- [Identity system testing](quality/identity-system-testing.md) defines the
  application matrix and checks.
- [Final delivery checklist](quality/final-delivery-checklist.md) covers
  files, rights, accessibility and handover.

The phases are described as gates, not as a promise of fixed duration. Change
an order only when dependencies and approvals remain explicit.
