# Studio knowledge

This directory records the studio's direction, audience assumptions, offer,
operating principles and decisions. Read the decision records when a document
conflicts with them: **decisions/ wins conflicts**.

| Document | Status | Use |
| --- | --- | --- |
| [Positioning](positioning.md) | Approved core; proposed elaboration labelled | Say what the studio is and can defend today |
| [Initial ICP](initial-icp.md) | Hypothesis | Qualify discovery and test the initial audience |
| [Strategic rationale](strategic-rationale.md) | Proposed | Keep diagnosis, opportunity and strategic directions visible |
| [Portfolio strategy](portfolio-strategy.md) | Proposed | Build evidence through a small, honest body of work |
| [Brand Direction Sprint](brand-direction-sprint.md) | Hypothesis | Test a bounded entry offer |
| [Identity System offer](identity-system-offer.md) | Proposed workflow; approved scope | Define the flagship engagement |
| [Creative philosophy](creative-philosophy.md) | Approved principles; proposed applications | Turn principles into design choices |
| [Roadmap](roadmap.md) | Proposed | Sequence learning and operating work |
| [Decisions](decisions/README.md) | Mixed by record | Find the current decision and its evidence |

The studio has no recorded client work or outcomes. Method descriptions are
intentions and working standards, not proof of results. Hypotheses stay
labelled until evidence changes their status through a recorded decision.

See the founder-authored [positioning thesis](positioning.md) alongside the
[proposed strategic rationale](strategic-rationale.md). The founder document
is the source for its working thesis and promise; it remains unchanged here.
