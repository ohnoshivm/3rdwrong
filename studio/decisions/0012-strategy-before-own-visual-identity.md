# D-0012: Strategy before own visual identity

## Decision

Before another serious visual-identity attempt, define and explicitly approve
the personality, cultural perspective, verbal identity and conceptual
territory of 3RDWRONGS. The own-identity project remains in exploration until
that foundation is approved.

## Status

Proposed. It does not approve any visual element or candidate interpretation
of the name.

## Rationale

The previous direction of heavy grotesk typography, black backgrounds and
neon accents, along with familiar creative-agency aesthetics, was too
predictable. A verbal and conceptual foundation gives visual exploration a
specific strategic source rather than a category moodboard.

## Alternatives considered

Restart visual exploration immediately; polish the rejected direction; select
type and colour before the studio has a defined personality and conceptual
territory.

## Evidence

Documented: founding brief, 2026-10-22, records the rejected own-identity
direction. Proposed: the Phase 0 gate is a process recommendation from the
founder brief and *Founding Blueprint v1.0, 22 October 2026 ([founding source archive](../archive/founding-blueprint-v1.0.md))*.
No new visual direction is approved.

## Consequences

The [own-identity brief](../../projects/internal/3rdwrongs-identity/brief.md)
must complete and record Phase 0 approval before concepts or visual routes
begin. Approval of Phase 0 does not approve a logo, typeface, colour or
identity system.

## Revision triggers

Reconsider only if the founder explicitly changes the gate through a new
decision, or if the defined Phase 0 work proves unsuitable for the project.
